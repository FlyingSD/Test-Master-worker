| Бутон "Добави събитие" | ⛔ Скрит | ✅ Правилно |
| Бутон "Редактирай" | ⛔ Скрит | ✅ Правилно |
| Бутон "Изтрий" | ⛔ Скрит | ✅ Правилно |

**Проблем:**
Родителят вижда ВСИЧКИ събития, включително за групи в които няма деца.

**Пример:**
- Иван е в група "Космос"
- Родителят вижда събития за групи: "Космос", "Планети", "Звезди"
- Трябва да вижда САМО "Космос"

**Решение:**
```typescript
const myChildrenGroups = myChildren.map(s => s.group)
const filteredEvents = events.filter(event => {
  if (isParent) {
    return myChildrenGroups.includes(event.group)
  }
  return true
})
```

## 🔗 КАК СА СВЪРЗАНИ ФУНКЦИИТЕ

### Потребителски Flow - Родител:

```
1. Login → Автентикация → useAuth hook → role: 'parent'
                                           ↓
2. App.tsx проверява: isParent === true → показва ParentDashboardPage
                                           ↓
3. Layout.tsx филтрира менюто → показва само: Начало, Моите деца, Плащания, События
                                           ↓
4. Родителят кликва "Моите деца" → MyChildrenPage
                                           ↓
5. useStudentsByParent(parentId) → извлича само неговите деца от Firestore
                                           ↓
6. Показва карти с деца → кликва на дете → MyChildDetailPage
                                           ↓
7. Зарежда:
   - useStudentsByParent() → проверява дали детето е негово
   - usePayments() → филтрира плащания за това дете
   - useHomeworkByStudent() → зарежда домашни за това дете
```

### Проблем във Flow:

```
❌ Родител пише директно URL:
   https://app.svetlinki.com/students
                    ↓
   App.tsx НЕ проверява роля за /students route
                    ↓
   StudentsPage.tsx НЕ проверява userData.role
                    ↓
   Родителят вижда ВСИЧКИ ученици! 🚨
```

### Учителски Flow:

```
1. Login → role: 'teacher'
         ↓
2. Layout показва пълно меню:
   - Dashboard (DashboardPage - всички данни)
   - Ученици (StudentsPage - всички ученици)
   - Родители (ParentsPage - всички родители)
   - Плащания (PaymentsPage - всички)
   - Събития (EventsPage - може да редактира)
   - Присъствия (AttendancePage - маркира)
   - Склад (InventoryPage - управлява)
   - Отстъпки (DiscountsPage - управлява)
   - Разходи (ExpensesPage - вижда/добавя)
   - Репорти (ReportsPage - финансови данни)
         ↓
3. НЕ вижда:
   - Admin Panel (правилно блокиран)
   - Settings (но МОЖЕ да влезе през URL ❌)
```

// src/components/ProtectedRoute.tsx
import { Navigate } from 'react-router-dom'
import { useAuth } from '@/hooks/useAuth'

interface ProtectedRouteProps {
  children: React.ReactNode
  allowedRoles: ('admin' | 'teacher' | 'parent')[]
  redirectTo?: string
}

export default function ProtectedRoute({
  children,
  allowedRoles,
  redirectTo = '/'
}: ProtectedRouteProps) {
  const { userData } = useAuth()

  if (!userData || !allowedRoles.includes(userData.role)) {
    return <Navigate to={redirectTo} replace />
  }

  return <>{children}</>
}

// Използване в App.tsx:
<Route
  path="/students"
  element={
    <ProtectedRoute allowedRoles={['admin', 'teacher']}>
      <StudentsPage />
    </ProtectedRoute>
  }
/>

### 1. Firestore Security Rules

Добави правила в Firestore:

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    // Students collection
    match /students/{studentId} {
      // Родители виждат само своите деца
      allow read: if request.auth != null && (
        resource.data.parentIds.hasAny([request.auth.uid]) ||
        get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role in ['admin', 'teacher']
      );

      // Само учители и админи могат да създават/редактират
      allow write: if request.auth != null &&
        get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role in ['admin', 'teacher'];
    }

    // Payments collection
    match /payments/{paymentId} {
      // Родители виждат само плащания за своите деца
      allow read: if request.auth != null && (
        get(/databases/$(database)/documents/students/$(resource.data.studentId)).data.parentIds.hasAny([request.auth.uid]) ||
        get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role in ['admin', 'teacher']
      );

      allow write: if request.auth != null &&
        get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role in ['admin', 'teacher'];
    }

    // Parents collection - САМО учители и админи
    match /parents/{parentId} {
      allow read, write: if request.auth != null &&
        get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role in ['admin', 'teacher'];
    }
  }
}
```
